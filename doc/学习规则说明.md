# 学习规则说明

- 日期：2026-10-25
- 代码：`yuyansdk/src/main/java/com/yuyan/inputmethod/UserLearning.kt`

## 为什么替换 Rime 自带的学习

Rime 的学习速度、遗忘方式写死在引擎里，误选一次就能排到第一，配置文件只能整体开关。语燕的引擎又没有源码，所以关掉 Rime 的学习，改由 App 层自己学。

## 规则

| 规则 | 参数 | 说明 |
|---|---|---|
| 记录 | — | 每次整段上屏记一条"拼音 → 上屏的词"；逐字拼出的新词（三 + 溪）按整词"三溪"记 |
| 门槛 | `TOP_SCORE = 2.5` | 用过约 3 次才可能排第一；不够的最多排第二；本来就靠前的词不往后挪 |
| 遗忘 | `HALF_LIFE_DAYS = 30` | 权重每 30 天减半；低于 `MIN_SCORE = 0.5` 不再参与排序，低于 0.1 从文件删除 |
| 撤销 | `UNDO_WINDOW_MS = 30 秒` | 上屏后紧接着按删除键删掉刚上屏的词，这次不算；中间按了别的键就不算撤销 |
| 不学 | `MAX_TEXT_LENGTH = 20` | 英文模式、超过 20 个字的上屏内容不学 |

学习键是候选栏上方显示的拼音（如 `shi'jian`），全拼、双拼、九宫格显示的都是全拼，**三种方式共用一份学习记录**。

## 数据

- 学习记录：`files/learning.tsv`（应用私有目录），每行：拼音、词、权重、最后使用时间、使用次数
- 设置 → 输入法 → **我的词库**：查看、单个删除、全部清空

## 怎么关掉 Rime 的学习

Rime 的学习库在 `Android/data/<包名>/files/rime/pinyin.userdb/`。
启动时把其中的 `LOCK` 换成一个非空目录：LevelDB 建不了锁文件，打不开学习库；
Rime 的自动修复删不掉非空目录，也重建不了。所以整个会话里学习库都不可用，引擎只按系统词库排序。

- 第一次关闭时，原学习库改名备份为 `pinyin.userdb.bak`，没有删除
- 2026-10-25 起英文（`english.userdb`）、笔画（`stroke.userdb`）学习库也用同样方式关闭，原库同样备份为 `.bak`

## 密码框和无痕输入（2026-10-25）

在密码框（文字或数字密码）和应用标了 `IME_FLAG_NO_PERSONALIZED_LEARNING` 的输入框（如浏览器无痕模式）里：
- 三溪的学习规则暂停，不记录任何上屏内容（`PrivateInput.active`，在 `ImeService.onStartInput` 里更新）
- 剪贴板历史不记录在这些输入框里复制的内容
- 被系统标为敏感的复制内容（`ClipDescription.EXTRA_IS_SENSITIVE`，Android 13 起密码管理器会设置）任何时候都不记录

模拟器实测：在 WLAN“添加网络”的密码框里切到中文上屏，词库没有新增；同一页的“网络名称”框里上屏照常记入。

> 第一版用"同名空文件"占位，结果 Rime 的修复流程会把它挪走并重建一个空库，会话中可能恢复学习，
> 每次启动还多出一个备份目录。已改成上面的 LOCK 目录方案。

## 模拟器验证结果

| 场景 | 结果 |
|---|---|
| 误选一次"实践" | 排第二（时间候选之后），"时间"仍是首选 ✅ |
| 用 2 次 / 3 次"实践" | 2 次仍第二，3 次排第一 ✅ |
| 逐字拼出"三溪"后立刻删除 | 日志 `undo learning san'xi -> 三溪`，再打不出现 ✅ |
| 逐字拼出"三溪" 1 次 → 3 次 | 1 次后排第二，3 次后排第一 ✅ |
| 全拼学的词在小鹤双拼、九宫格里 | 同样排第一 ✅ |
| 我的词库删除"实践" | 恢复"时间"首选 ✅ |
| 重启输入法 | 学习记录还在 ✅ |
| 关闭 Rime 学习后选一次"世间" | 只到第二，说明引擎不再自己学 ✅ |

## 已知限制

- 只学整段上屏的内容，Rime 原来会自动记住的整句片段不再学
- 学到的新词只在拼音完全一致时出现，打一半（如 `sanx`）不会出现
- 学习记录只在本机，没有导出/导入（语燕原有的数据导出不包含 `learning.tsv`）
