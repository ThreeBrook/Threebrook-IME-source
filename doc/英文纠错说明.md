# 英文拼写纠错说明

- 日期：2026-10-25
- 代码：`yuyansdk/src/main/java/com/yuyan/inputmethod/EnglishCorrector.kt`
- 词表：`yuyansdk/src/main/assets/english/en_words.txt`（46717 词，来自 FrequencyWords 的 OpenSubtitles 2018 英文 5 万词频表，CC BY-SA 4.0，见同目录 README.txt）

## 效果

只在英文模式生效。候选顺序：**原样输入 → 纠错建议（最多 3 个）→ 原有的补全候选**。
空格仍上屏原样输入，不会自动替换；想要纠正后的词点一下即可。

| 输入 | 候选 |
|---|---|
| tomorow | tomorow · **tomorrow** |
| beautifull | beautifull · **beautiful** · beautifully |
| recieve | recieve · **receive** · believe · received |
| teh | teh · **the** · tehran |
| dont | dont · **don't** · don · done |
| jsut / hwllo | **just** / **hello** |
| hello / thanks | 拼写正确，不出纠错 |

## 算法

在词表建成的字典树上做带权编辑距离搜索：
- 插入、删除、替换各算 1，**打成键盘上相邻的字母算 0.6**，相邻两字母打反算 0.8
- 3–4 个字母最多允许改 1 处，5 个及以上最多 2 处；少于 3 个字母不纠错
- 排序：词频越高、改动越少越靠前（每多 1 处改动相当于词频差 e⁴ 倍）
- 词表里有字幕中的常见错拼（helo、untill、realy……），所以输入本身在词表里时，只推荐比它常见 20 倍以上的词；正确的常用词因此不会冒出建议
- 不到最佳建议词频 1% 的词（多为错拼、人名）不推荐
- 词表把 don't 拆成了 don + t，另外补了一张常用缩写表（dont → don't、im → i'm 等 33 个）

电脑上的原型测试 31 个用例全部通过；模拟器里实测结果见上表。

## 限制

- 只纠正单个单词，不看上下文（比如 their / there 不会互相纠正）
- 不学习你的英文用词习惯
- i'm 显示为小写（英文候选统一按大小写状态转换，句首大写跟随键盘的 Shift 状态）
